## Схема индекса и логика ранжирования

### Схема индекса Elasticsearch

Индекс products настроен со следующими полями:

Текстовые поля с префиксным поиском:

- name - название товара (основное поле)

- category - категория товара

- brand - бренд производителя

- keywords - ключевые слова для поиска

- Числовые и служебные поля:

- price - цена товара (float)

- weight - вес товара

- package_size - размер упаковки

- id - идентификатор товара

### Логика ранжирования

Multi-match запрос с весами:

```bash
fields = [
    "name^4",        # Название - самый высокий приоритет
    "brand^3",       # Бренд 
    "category^2",    # Категория
    "keywords^2"     # Ключевые слова
]
```

## Снижение количества "мусора" в выдаче

### Стратегии фильтрации

**Приоритизация релевантных полей:**

- Бусты по name (×4) и brand (×3) обеспечивают приоритет точным совпадениям

- Категория и keywords имеют меньший вес для избежания шума

**Пороговая фильтрация:**

- Минимальный score для попадания в результаты

- Требование совпадения хотя бы одного ключевого атрибута

**Контекстная релевантность:**

- Запросы с числовыми атрибутами, но ищутся в соответствующих полях

- Короткие префиксы требуют точного совпадения начала слов

### Методы обработки запросов

**Нормализация ввода:**

- Приведение к нижнему регистру

- Удаление лишних пробелов

- Базовая транслитерация латинских символов

**Исправление раскладки:**

- Автоматическое преобразование qwerty → йцукен

- Обработка смешанных раскладок

## Если бы это шло в прод

### Мониторинг и алерты

**Метрики производительности:**

- QPS (queries per second) - нагрузка на систему

- P95/P99 latency - время ответа для 95%/99% запросов

- Error rate - процент ошибочных ответов

**Метрики качества:**

- Success rate - процент запросов с релевантными результатами

- Precision@K - точность топ-K результатов

- CTR (Click-Through Rate) - кликабельность выдачи

**Алерты:**

- Success rate < 80% более 5 минут

- P95 latency > 100ms более 10 минут

- Error rate > 5% более 2 минут

- Отсутствие данных от Elasticsearch
